Publish and Share

1. Upload to GitHub

Upload this file to your repository and name it index.html.

2. Enable GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, then select main and /(root).

3. Open the published site

Wait for deployment, then open your GitHub Pages address. It usually looks like https://username.github.io/repository/.

4. Share the QR code

Download the QR PNG on Page 1 and share it. Anyone with the link can visit your public site.

GitHub Pages hosts static files. It does not run a Python server or expose an HTTP server running on your Android phone.
